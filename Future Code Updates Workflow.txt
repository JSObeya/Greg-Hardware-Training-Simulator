Future Code Updates Workflow
Whenever you make updates locally and want them live on Hostinger:

Locally in Laragon:

powershell

npm run build
git add .
git commit -m "Your update description"
git push origin main
On Hostinger via SSH:

bash

cd ~/domains/gregicthub.com/public_html/hardware
git pull origin main
php artisan migrate --force
php artisan config:cache
php artisan route:cache
php artisan view:cache
